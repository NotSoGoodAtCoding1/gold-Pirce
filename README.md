# Gold Price Prediction - Neural Network

A time-series deep learning model for predicting gold (GLD ETF) prices using historical market data. Features automatic CUDA/CPU support and proper data leakage prevention.


## Performance Metrics

The model reports these metrics on the original price scale:
- **RMSE** - Root Mean Squared Error
- **MAE** - Mean Absolute Error
- **MASE** - Mean Absolute Scaled Error
- **R² Score** - Coefficient of determination



This project is for educational purposes.
